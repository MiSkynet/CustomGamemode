# CustomGamemode

The CustomGamemode Plugin is a plugin for [Minecraft Paper 26.2](https://fill-ui.papermc.io/projects/paper/version/26.2).
I'm trying to create a custom gamemode for Minecraft, that enhances the gameplay and creates a unique experience for the players,
even though I'm not a professional developer and got limit knowledge of Java etc.

A more detailed description of the plugin will follow in the future, but for now, I'm focusing on keep developing more features
into the plugin to create a fully working gamemode.
